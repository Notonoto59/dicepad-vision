# DicePad Vision

Application Web gratuite de reconnaissance de 1 a 5 des a six faces avec la camera d’un smartphone Android.

L’application traite les images sur l’appareil, sans les transmettre a un serveur. Elle propose les faces brutes (1 a 6) et l’attribution aleatoire de dizaines (11 a 56).

## Utilisation

Ouvrir https://notonoto59.github.io/dicepad-vision/ sous Chrome Android, autoriser la camera, puis installer l’application depuis le menu du navigateur.

L’affichage de demonstration peut etre active sans camera. Utiliser des des contrastes sur fond uniforme, bien espaces. Les performances reelles dependent de l’eclairage, du cadrage et du modele de telephone.
