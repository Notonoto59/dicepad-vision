# DicePad Vision

Application Web installable sur Android pour reconnaître de 1 à 5 dés D6 à partir de la caméra du smartphone, sans envoyer d’images à un serveur.

- Mode faces physiques (1–6)
- Mode valeurs (11–56) avec dizaines attribuées sans répétition
- Correction manuelle, rotation et inversion pour l'utilisation avec miroir
- Export JSON et historique local
